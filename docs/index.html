Grounded Hypercalculi

Because there are more calculi than just maths'.

A unified formal framework and computational library implementing extended mathematical, symbolic, structural, and computational calculi under pure standard library Python 3.10+.

The Six Extended Calculi

1. Language Calculus

Formal syntax trees, alphabet specifications, context-free production rules, reflexive non-well-founded quotation graphs under Aczel's AFA, and verified Metamath RPN proof validation.

2. Meta-Calculus

Symbolic dynamics of term rewrite systems, infinite trajectory spaces, shift operators, coalgebraic trajectory bisimulation, and Coxeter word-homotopy.

3. Hyper-Calculus

Automorphism groups over semantic state spaces, permutation groups, Lie derivation algebras with Leibniz product rule and Lie commutator brackets preserving Noether invariants.

4. Ordinal Calculus

Exact transfinite arithmetic below ωω, left subtraction, discrete difference operators, normal functions, ordinal derivatives enumerating fixed points, and Veblen hierarchies.

5. Real Analysis Calculus

Continuum constructions grounded in hyperset ordinals, Dedekind cuts, Cauchy rational sequences, and Conway Surreal numbers supporting transfinite numbers and infinitesimals.

6. Oracle Calculus

Hypercomputation, trans-ω leapfrog computations (O(ωω) in unit time), ω-towers of halting oracles, hyperoracles, and contractive conclusion analysis.

Quickstart

import grounded_hypercalculi as gh

# Ordinal arithmetic and limits
omega = gh.OMEGA
alpha = gh.BoundedOrdinal.from_int(1)
assert (alpha + omega) == omega

# Turing degree jump in Oracle Calculus
deg0 = gh.TuringDegree(0)
assert deg0.is_computable
deg1 = deg0.jump()
assert deg1.rank == 1

# Leapfrog trans-omega computation
leap = gh.LeapfrogComputation(1)
result = leap.leapfrog_step(0, lambda s, i: s + 1, 10)
assert result == 10

# Grounded rationals and reals
rat = gh.GroundedRational(1, 2)
assert rat.to_float() == 0.5
